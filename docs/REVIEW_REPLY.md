# 处理复查人的一句话回复（图纸识别报告）

适用：复查人看完「图纸识别报告」（或核对用 DWG）后，用一句话回复，例如：

> 面积正确。E53 正确，E63 是货架，E65 是提升机不是堆垛机，其余正确；左下角一排输送机未识别。

agent 照下面四步做，不另做界面。

## 1. 对应编号

- 报告第三部分每处都有编号（E53 等）。复查人说"其余正确"时，只适用于报告里**展示过**的编号（`review/second_look/archive.json` 与报告第三部分一致），没展示过的不算人工核对。
- "面积正确 / 面积通过" 对应厂房尺寸那一页。
- 说不清对应哪个编号的，**不要猜**，在第 2 步里问回去。

## 2. 先复述，等对方确认

用一张小表复述理解，例如：

| 编号 | 系统识别 | 您的判断 |
|---|---|---|
| 面积 | 12,629 m²（示例） | 正确 |
| E53 | 货架 | 正确 |
| E63 | 托盘滚筒输送机 | 改为：货架 |
| E65 | 堆垛机 | 改为：提升机 |
| 其余 3 处 | 按系统识别 | 正确 |
| 未识别 | — | 左下角一排输送机 |

对方回复"对"以后再执行。复查人的原话逐字存到 `review/reply.txt`（附日期），作为人工核对的依据。

## 3. 执行

- 面积：正确 → `py -3.11 -X utf8 -m scripts.trial_package finish --out <输出文件夹>/area --passed --confirmer <复查人> --minutes <用时>`；对方交回改过的 DWG → 用 `--returned-dwg`。
- 设备：把判断写进 `review/设备复查表.csv` 的"复查"栏（`对` / `不是设备` / 正确类型名，中文类型名见 `cad_to_layout/zero_manual/equipment.py` 的 `LABEL_ZH`），未识别的位置写进最后一行，然后
  `py -3.11 -X utf8 scripts/equipment_review.py apply --run <输出文件夹>/equipment --table <填好的表> --reviewer <复查人> --minutes <用时>`。

## 4. 回报

把 `设备结果（复查后）.md` 和面积 `result/最终结果.md` 的要点用产品语言回给对方：哪些已人工核对、哪些人工修正、还有哪些未核对。不得把"人工核对后正确"说成"系统识别准确"。
